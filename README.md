# 調剤算定リファレンス（令和8年度）

略号、項目名、制御コード、算定条件を自由検索できる静的Webサイトです。

## GitHub Pagesで公開する

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** にします。
3. **Branch: main / フォルダ: /(root)** を選び、**Save** を押します。

公開完了後のURLは `https://noine32.github.io/recept_kasan/` です。初回反映には数分かかる場合があります。

## 収録内容

- 添付表の90行。略号が同じでも、算定する本体の違う行を統合していません。
- 算定可否の具体例46件。通知を基にした解説で、審査事例の収集ではありません。
- 調剤点数表と調剤留意事項の全文。
- 厚生労働省の疑義解釈その1〜12、その2訂正（令和8年9月2日公表分まで）。
- 特掲施設基準の薬局関連ページ、給付調整・特別養護老人ホーム関連通知。
- 原PDFへのページ指定リンク、元表の説明と修正・補足の区別。

## 確認状況

**「実際に算定できる全パターンを網羅した完成版」ではありません。**
原資料を検索できる範囲と、事例の解説が整備された範囲を区別しています。

原表の全略号・制御コード・点数の照合、過年度疑義解釈の有効性判定、個別事例の全組合せ、通知間の全参照関係の整理は未完了です。PDFの抽出テキストは表組みや改行が崩れることがあるため、表の判断は原PDFを参照してください。一般的な共通要件や施設基準を満たすかは、各項目の原文も確認する必要があります。

重要な補足として、外来服薬支援料2の7日ごとの計算、服用薬剤調整支援料2の令和9年6月開始、吸入薬指導加算のインフルエンザ、残薬調整の6日以下・数量0の条件を掲載しています。

## 使い方

「残薬 6日」「吸入 インフルエンザ」「8.1116」などで検索します。空白区切りのAND検索、全角・半角の正規化、頓服／屯服の表記差に対応しています。検索語と検索対象はURLに残るため、検索結果をブックマークできます。

APIキー、ログイン、外部の検索サービスは不要です。検索文字列は検索サービスに送信されません。個人の患者情報を入力する用途は想定していません。

## 更新方法

`data.json` がWeb公開用データ、`cases.json` が編集用の事例です。`sources/manifest.json` に出典一覧があります。初期確認日は2026-09-08です。

再生成する場合はPython 3とPoppler（pdftotext）が必要です。

```sh
python download_sources.py
python build_data.py path/to/input.xlsx
```

生成先は `dist/` です。生成後、`dist/index.html`、`dist/style.css`、`dist/app.js`、`dist/data.json` をリポジトリ直下に反映します。HTML/CSS/JSの編集元も `dist/` として管理しています。

新しい疑義解釈を追加しただけでは、事例の正しさが自動で再検証されるわけではありません。資料の適用日・訂正関係を確認し、影響する事例と補足を修正してください。
